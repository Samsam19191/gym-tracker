Settings (gear icon on Home)

  • Add, rename, recolor and reorder workout types.
  • Screen-on, rest target and kg / lb.
  • S8Export saves one backup file to Files or iCloud Drive. The app reminds you if your last backup is more than 30 days old.

My suggestions

S1
"Up next" on Home. Highlights the next type in your Push → Pull → Shoulders rotation, based on your last workout.
S2
Undo a set. "−1" on the set counter, for accidental taps.
S3
Weights during a workout. Open your machine weights from the workout screen while the timers keep running.
S4
Optional rest target. Ring fills up, short sound when reached. Sound only: iPhone web apps can't vibrate.
S5
Average rest per workout. Free data, since every rest is already timed.
S6
Add a workout by hand. For the days you forgot to start the timer.
S7
One weight per machine per day. Logging twice keeps the higher one, so the chart stays clean.
S8
Backup reminder. Nudge on Home if your last export is over 30 days old.

Built in, and later

Timers survive anything. The app saves when each timer started, not a running count. If you lock the phone, switch apps or iOS closes the app, the timers are still exact when you come back.

Stats page (not in v1). Everything above is saved from day one: durations, sets per exercise, rest times, weights. A later Stats tab can then show trends with filters (by type, by month): workouts per week, average duration, sets per workout, rest time, weight progress across machines. Your whole history will already be there.
